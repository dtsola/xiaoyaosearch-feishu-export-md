## 核心模块说明

### **1. commands/ - CLI命令层**

负责命令行参数解析和用户交互，调用core层完成业务逻辑。

| 文件 | 职责 |
|------|------|
| `init.ts` | 初始化配置，交互式引导用户输入 |
| `config.ts` | 配置查看、更新、重置 |
| `export/doc.ts` | 单文档导出命令 |
| `export/docs.ts` | 批量文档导出命令 |
| `export/folder.ts` | 文件夹导出命令 |
| `export/wiki.ts` | 知识库导出命令 |
| `export/wiki-node.ts` | 知识库节点导出命令 |

### **2. core/ - 核心业务逻辑**

包含核心业务逻辑的抽象层。

| 文件 | 职责 |
|------|------|
| `auth.ts` | Token获取、刷新、缓存管理 |
| `document.ts` | 文档块获取、文档解析 |
| `wiki.ts` | 知识库树遍历、节点获取 |
| `media.ts` | 图片、附件下载处理 |

### **3. converter/ - 格式转换**

负责将飞书富文本转换为Markdown格式。

| 文件 | 职责 |
|------|------|
| `markdown.ts` | Markdown转换器主入口 |
| `blocks.ts` | 各种飞书块类型处理逻辑 |
| `types.ts` | 转换器类型定义 |

### **4. api/ - API客户端**

封装飞书开放平台API调用。

| 文件 | 职责 |
|------|------|
| `client.ts` | Axios实例、拦截器配置 |
| `auth.ts` | 认证API（获取tenant_access_token） |
| `document.ts` | 文档API（获取文档块） |
| `wiki.ts` | 知识库API（获取节点树） |
| `media.ts` | 媒体API（下载资源） |

### **5. utils/ - 工具模块**

通用工具函数和辅助模块。

| 文件 | 职责 |
|------|------|
| `config.ts` | 配置文件读写、多租户管理 |
| `rate-limiter.ts` | 基于bottleneck的速率限制 |
| `progress.ts` | 进度条显示、统计信息 |
| `logger.ts` | Winston日志配置 |
| `file.ts` | 文件操作辅助函数 |
| `retry.ts` | 重试逻辑、指数退避 |
| `cache.ts` | Token缓存、元数据缓存 |

### **6. types/ - 类型定义**

TypeScript类型声明文件。

| 文件 | 职责 |
|------|------|
| `index.ts` | 全局类型导出 |
| `config.ts` | 配置相关类型 |
| `feishu.ts` | 飞书API响应类型 |
| `export.ts` | 导出选项、结果类型 |

### **7. constants/ - 常量定义**

全局常量和枚举。

| 文件 | 职责 |
|------|------|
| `index.ts` | 常量统一导出 |
| `api.ts` | API端点、错误码 |
| `config.ts` | 默认配置值 |
| `error.ts` | 错误消息模板 |

## 代码规范

### **命名约定**

| 类型 | 命名风格 | 示例 |
|------|---------|------|
| 类/接口/类型 | PascalCase | `ConfigManager`, `AuthClient` |
| 函数/变量 | camelCase | `getAccessToken()`, `configPath` |
| 常量 | UPPER_SNAKE_CASE | `MAX_RETRIES`, `API_ENDPOINT` |
| 文件名 | kebab-case | `rate-limiter.ts`, `markdown.ts` |
| 接口（非组件） | `I`前缀 | `IConfig`, `IFeishuBlock` |

### **目录约定**

- **commands/**: 每个命令一个文件，导出命令注册函数
- **core/**: 按业务模块划分，每个模块一个文件
- **converter/**: 转换相关逻辑，保持独立性
- **utils/**: 纯函数优先，无副作用的工具
- **api/**: 按API模块划分，返回类型化数据

### **代码风格**

- 使用 **ESLint** 进行代码检查
- 使用 **Prettier** 进行代码格式化
- 使用 **TypeScript** 严格模式
- 导入顺序：外部库 → 内部模块 → 类型导入
- 文件头部注释说明模块功能
