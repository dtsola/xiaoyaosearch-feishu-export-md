# 飞书导出工具 - 手动测试步骤

## 前置准备

### 1. 飞书应用配置

1. 访问 [飞书开放平台](https://open.feishu.cn/app)
2. 创建自建应用
3. 开通权限：
   - `docx:document:readonly` - 获取文档内容
   - `drive:drive:readonly` - 获取文件/图片
   - `wiki:wiki:readonly` - 获取知识库
4. 发布应用并等待审批通过
5. 记录 App ID 和 App Secret

### 2. 安装工具

```bash
cd /path/to/xiaoyaosearch-feishu-export-md
npm install
npm run build
npm link
```

## 功能测试

### 测试 1: 初始化配置

**命令:**
```bash
feishu-export init
```

**验证点:**
- [ ] 提示输入 App ID
- [ ] 提示输入 App Secret
- [ ] 提示输入默认输出目录
- [ ] 配置文件创建成功 (`~/.feishu-export/config.json`)

**查看配置:**
```bash
cat ~/.feishu-export/config.json
```

---

### 测试 2: 配置管理

#### 2.1 获取配置
```bash
feishu-export config get
```

**验证点:** 应显示当前配置的所有值

#### 2.2 设置配置
```bash
feishu-export config set appId your_app_id
feishu-export config set appSecret your_app_secret
```

**验证点:** 配置更新成功

#### 2.3 列出配置
```bash
feishu-export config list
```

#### 2.4 重置配置
```bash
feishu-export config reset
```

**验证点:** 配置恢复默认值

---

### 测试 3: 导出单个文档

**准备:** 获取一个飞书文档的 document_id（从 URL 中提取）

**命令:**
```bash
feishu-export export -d doxcnXXXXXXXXXXXX
```

**验证点:**
- [ ] 成功导出 Markdown 文件
- [ ] 图片正确下载
- [ ] 文件名合法（无非法字符）
- [ ] Markdown 格式正确

**指定输出目录:**
```bash
feishu-export export -d doxcnXXXXXXXXXXXX -o ./test-output
```

---

### 测试 4: 导出知识库文档

**命令:**
```bash
feishu-export export -w wiki_node_token
```

**验证点:**
- [ ] 成功导出知识库文档
- [ ] 目录结构正确

---

### 测试 5: 批量导出文档

#### 5.1 创建文档列表文件

创建 `docs.txt`:
```text
doxcnDocId1
doxcnDocId2
doxcnDocId3
```

**命令:**
```bash
feishu-export docs --file docs.txt -o ./batch-output
```

**验证点:**
- [ ] 所有文档成功导出
- [ ] 进度条正常显示
- [ ] 错误处理正常

#### 5.2 命令行指定 ID 列表

```bash
feishu-export docs --ids doxcnId1,doxcnId2 -o ./batch-output
```

---

### 测试 6: 增量导出

**首次导出:**
```bash
feishu-export docs --file docs.txt -o ./incr-output --incremental
```

**再次导出（应跳过未修改文档）:**
```bash
feishu-export docs --file docs.txt -o ./incr-output --incremental
```

**验证点:**
- [ ] 显示 "已跳过" 消息
- [ ] 未修改文档不重新导出

---

### 测试 7: 并发控制
